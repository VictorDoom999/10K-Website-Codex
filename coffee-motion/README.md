# AUREL Coffee Motion Graphic

A 12-second, 1080 × 1920 premium coffee brand motion graphic made in Remotion. AUREL is a placeholder brand name. The composition is silent.

## Preview

```bash
npm ci
npm run studio
```

Open the `CoffeeSpot` composition in Remotion Studio.

## Render

```bash
npx remotion render src/index.ts CoffeeSpot aurel-coffee-spot.mp4
```

The included MP4 is the current render. `src/spot.tsx` contains the animated vector artwork and typography.
